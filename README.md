# Vision 2030 Water-Saving Assistant

## Project Overview
The Vision 2030 Water-Saving Assistant is a simple Python project that provides water conservation advice based on daily water usage.

It supports Saudi Vision 2030's sustainability goals and the United Nations Sustainable Development Goal 6 (Clean Water and Sanitation).

## Objectives
- Encourage responsible water consumption.
- Provide simple water-saving recommendations.
- Raise awareness about water conservation.
- Demonstrate a basic rule-based decision-support system.

## Technologies Used
- Python 3
- GitHub

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python main.py
```

5. Enter your estimated daily water use in liters.

## Example
Input: `150`

Output: A recommendation to take shorter showers and turn off taps when not needed.

## SDG Alignment
- **SDG 6:** Clean Water and Sanitation
- **SDG 12:** Responsible Consumption and Production

## Limitations
This is an educational prototype. It uses simple rules and does not measure actual water consumption or use a trained AI model.
